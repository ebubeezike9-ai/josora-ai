JOSORA AI

Your Personal AI Assistant

JOSORA AI is an independent AI application project focused on creating a personalised assistant that helps users interact with AI, manage conversations, and access intelligent digital tools.

About the Project

JOSORA AI is being developed with the goal of making AI assistance more accessible, interactive, and personalised.

The project involves building both the user interface and the supporting application infrastructure, with an emphasis on practical software development, API integration, and user experience.

Technologies Used

- Flutter – Cross-platform application development
- Dart – Application programming
- Node.js – Backend development
- Express.js – Backend API framework
- SQLite – Database management
- AI API integration – AI-powered conversation capabilities

Development Highlights

- AI-powered chat interface
- User authentication and session handling
- Chat history management
- Personalised memory functionality
- Backend and API integration
- Application debugging and iterative development
